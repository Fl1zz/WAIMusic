## РУССКИЙ

---

### Описание

Мод добавляет удобный, гибко настраиваемый внутриигровой плеер для прослушивания музыки прямо во время игры. Поддерживает пользовательские треки, плейлисты и полностью кастомизируемый оверлей.

### Возможности

* **Импорт треков** в форматах:
    * MP3
    * OGG
    * WAV
    * AIFF
* **Импорт плейлистов** - из JSON-файла или сразу нескольких аудиофайлов
* **Создание плейлистов** из треков личной библиотеки
* **Редактирование очереди воспроизведения**, в том числе внутри плейлистов
* **Гибкая настройка:**
    * внешний вид оверлея
    * внешний вид плеера
    * отображение отдельных элементов оверлея
    * положение и прозрачность оверлея
    * выбор микшера
* **Удаление треков и плейлистов**
* **Встроенные треки и плейлисты** - можно упаковать прямо в `.jar` мода

### Примечания

* Если в метаданных трека нет длительности, мод просто не будет её отображать.
* Обложка подтягивается из метаданных. Если её там нет - придётся указать вручную.
* При очень быстром переключении треков звук может начать ломаться.
  Для исправления просто перезапусти плеер.

## *ENGLISH*

---

### Description

A convenient, highly customizable in-game music player for Minecraft. Supports user tracks, playlists, and a fully customizable overlay.

### Features

* **Track import** in formats:
    * MP3
    * OGG
    * WAV
    * AIFF
* **Playlist import** - from a JSON file or multiple audio files at once
* **Playlist creation** from your personal library
* **Playback queue editing**, including within playlists
* **Extensive customization:**
    * overlay appearance
    * player appearance
    * visibility of individual overlay elements
    * overlay position and transparency
* **Track and playlist removal**
* **Built-in tracks and playlists** - can be bundled directly into the mod's `.jar`

### Notes

* If a track's metadata has no duration, the mod simply won't display it.
* Cover art is pulled from metadata. If missing, you'll need to set it manually.
* Rapidly switching tracks may cause audio glitches.
  Toggling player off and on again fixes it.
